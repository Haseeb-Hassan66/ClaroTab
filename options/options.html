ClaroTab Settings

AI categorization

Most tabs are grouped instantly by ClaroTab's built-in rules, with no network access needed. For the few tabs the rules can't confidently place, ClaroTab can optionally ask Google's Gemini API to classify them. This is completely optional -- everything else works fully without it.

AI model

ClaroTab automatically switches between models when one runs low on its free quota, so categorization keeps working without interruption. You can also pin a specific model below — ClaroTab will still fall back automatically if your pinned choice becomes unavailable.

Google doesn't expose your actual quota, so ClaroTab only shows what it can verify: the real number of requests it has sent to each model today, tracked locally. A model is marked "exhausted" only after ClaroTab actually receives a rate-limit response from it — no guessed limits or percentages.

Privacy

Your key is stored only on this device, in your browser's local extension storage. It's never sent anywhere except directly to Google's API when classifying a tab, and only the title/URL of tabs the rule engine couldn't already categorize are ever sent.
